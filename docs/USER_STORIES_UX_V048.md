# Axon-x 交互与工作流体验升级 — 用户故事与验收标准 (User Stories)

> 版本：v0.4.8 交互升级专项 · 对齐 `Spec 1 ~ Spec 6`
> 目标：解决「知识只读看图难操作、双轨项目选择割裂、图谱与历史会话断层、缺少全局快捷入口」四大交互痛点，把 Axon-x 从「静态知识查看器」升级为「高频可写、双向溯源、键盘优先的个人与团队知识工作台」。

---

## 1. 核心角色与真实使用场景

### 角色 A：「阿轩」—— 多项目并行、重度使用 AI Agent 的资深研发
- **日常状态**：本机沉淀了 7+ 个知识域（如 `wanlian` 1000+ 实体、`axon` 670+ 实体、`glite` 等）和上千条 Claude Code / Codex / WorkBuddy 会话；同时维护多个仓库目录。
- **核心场景**：
  1. **开工前查背景 / 复盘知识**：打开 Axon-x 快速找到某个模块/服务的既有结论，确认这条结论是哪次对话得出的、有没有过时。
  2. **纠偏与治理知识图谱**：发现大模型提炼出的某条事实不准、或者两个实体名字写重了，随手在界面上改掉或删掉，避免下次 MCP 召回错误知识误导 Agent。
  3. **顺手记一条经验**：刚在生产/测试环境踩完一个坑（未经过长对话提炼），想花 15 秒直接在桌面端补一条确定性规则进知识图谱。

### 角色 B：「新接入的同事」—— 导入 `.axon-kb` 知识包或初次上手的开发者
- **日常状态**：使用 OpenAI / 智谱 GLM 等不同模型服务，没有内部私有网关 `gpt-5.6-sol`；刚拿到阿轩分享的知识包或刚克隆仓库。
- **核心场景**：
  1. **零报错完成首次建图**：配好自己的 API Key 和默认模型后，点「建索引」就能直接跑通，而不会因为硬编码私有模型名报错。
  2. **顺畅浏览大图**：导入上千节点的知识包后，能像用地图软件一样滚轮缩放、拖拽平移、搜索关键词直接定位到目标节点。

## 2. 用户故事地图（按 6 大核心体验旅程组织）

### 旅程一：工作区导航与项目/知识域切换（对应 Spec 1 & Spec 6）

- **US-1.1【统一项目与知识域选择】**
  - **作为**阿轩，**我想要**在左侧栏底部只用一个统一的「项目与知识域」列表来切换当前上下文（替代原先分裂的「项目下拉框」+「图谱标签云」），**以便**我点击任意项目时，「知识图谱」「历史会话」「全文搜索」自动对齐到同一个项目，不用在两个选择器之间反复猜测。
  - **验收标准 (AC)**：
    - [x] 已建立图谱的项目默认展示在主列表中，同时显示实体数量徽章（如 `1026`）与同域自动归组标识（如 `+1`）。
    - [x] 尚未建图谱的会话目录默认折叠在底部「未建图谱的会话目录 (N)」，展开后可查看会话数并点击切换。
    - [x] 当项目/知识域总数超过 5 个时，顶部提供实时筛选输入框，输入字母即可过滤。

- **US-1.2【按需叠加多知识域对比】**
  - **作为**阿轩，**我想要**默认单击切换单个知识域（含其自动归组的同域伙伴），同时能点右侧 `+` 按钮（或按住 `⌘/Shift` 点击）把另一个知识域（如 `glite` 与 `wanlian`）临时叠加到同一张图里对比，**以便**查看跨项目的共享组件与依赖关系，看完后能点「仅看单个」一键恢复。
  - **验收标准 (AC)**：
    - [x] 单击某一项：设为唯一主选知识域。
    - [x] 点击某一项右侧的 `+`（变 `✓`）：将该知识域加入多域合并视图；多选状态下顶部出现「仅看单个」快捷复位按钮。

- **US-1.3【完整视图导航与键盘优先切换】**
  - **作为**阿轩，**我想要**在左侧导航栏直接看到「知识 (`⌘1`)、会话 (`⌘2`)、终端 (`⌘3`)、设置 (`⌘4`)」四个主入口，跨会话全文检索收敛进 `⌘K` 全局面板，并能用 `⌘B` 随时把侧边栏折叠成窄图标栏，**以便**在小屏幕或看大图时腾出最大画布空间，且全程不用伸手摸鼠标就能切视图。
  - **验收标准 (AC)**：
    - [x] 侧边栏挂载四个主视图。原先孤立的 `SearchView` 全文检索能力**并入 `⌘K` 面板**（复用 `SearchSessions`），不再单独成页；`TasksView` 任务编排页本期下线，后端 `orchestrate.go` 的任务能力保留，待后续接回界面。
    - [x] 按 `⌘1` ~ `⌘4` 立即切换到对应视图；按 `⌘K` 呼出全局检索；按 `⌘B` 侧边栏在 `196px` 展开态与 `48px` 极简图标态之间平滑切换。

### 旅程二：大图画布自由探索与精准定位（对应 Spec 2 前半）

- **US-2.1【地图式滚轮缩放与拖拽平移】**
  - **作为**阿轩，**我想要**在知识图谱画布上用触控板/鼠标滚轮以光标为中心自由缩放（35% ~ 350%），并在空白处按住左键拖拽平移画布，**以便**在节点密集时放大看清局部关系标签，在迷失方向时点左上角「`100%`」一键复位居中。
  - **验收标准 (AC)**：
    - [x] 滚轮缩放以当前鼠标位置为锚点平滑缩放，且拖拽单个节点微调位置时坐标换算依然精准（不受缩放/平移偏移影响）。
    - [x] 画布左上角常驻 `+` / `100%` / `−` 控件，点击百分比数字立即复位到 `zoom=1, pan=(0,0)`。

- **US-2.2【全字段实时联想搜索（含别名与事实）】**
  - **作为**阿轩，**我想要**在图谱顶栏搜索框输入关键词时，不仅搜节点名称，还能匹配节点的**别名（Aliases）、类型、以及事实正文（Observations）**，并实时弹出匹配下拉列表告诉我「为什么命中」，**以便**我记不清标准实体名（比如只记得英文缩写或某句报错描述）时也能一下回车跳过去。
  - **验收标准 (AC)**：
    - [x] 输入关键词实时弹出最多 8 条候选，展示实体名、类型标签及命中的具体原因（如 `别名: xxx` 或命中的那条事实文本）。
    - [x] 支持 `↑` / `↓` 键选择候选、`Enter` 键直接将画布聚焦并复位居中到该节点。

### 旅程三：知识图谱直改与随手录入（对应 Spec 2 后半 & Spec 3）

- **US-3.1【自动合并视图下直接修改/审核知识（解除只读锁死）】**
  - **作为**阿轩，**我想要**在系统「自动归组」（如 `wanlian + Wanlian1` 合并显示）或手动多域对比视图下，依然能直接编辑事实、确认/降级/删除关系、重命名或删除实体，**以便**我不必为了改一个错别字去拆开合并视图或猜它到底存在哪个子目录里。
  - **验收标准 (AC)**：
    - [x] 后端所有治理接口（`DeleteEntity`、`UpdateEntityObservations`、`RenameEntity`、`ReviewAssertion`、`ReviewRelation`、`UndoLastGraphReview`）自动遍历当前合并域定位目标实体/关系所在的命名空间缓存并持久化。
    - [x] 详情面板新增 `✎` 实体重命名按钮，改名后自动将旧名称加入该实体的 `Aliases`，并同步更新所有关联边的端点名称。

- **US-3.2【桌面端 15 秒手动记一条知识】**
  - **作为**阿轩，**我想要**点击知识页顶栏醒目的「`+ 记一条知识`」按钮，在弹窗里填好实体名、类型、别名、核心事实和可选的关联目标，一键写进当前项目图谱，**以便**我临时总结出的架构红线或排查经验不用非得开终端让 Agent 调 MCP 才能入库。
  - **验收标准 (AC)**：
    - [x] 手动录入的事实自动标记为 `manual` 来源、`verified` 状态与 `100%` 置信度，若开启语义模式还会自动生成向量，保存后画布立即聚焦到新节点。
    - [x] 顶栏原有的低频构建操作（从历史对话建索引、从代码仓库建图、吸收 Obsidian 笔记、导出/导入知识包）统一收纳进「`⚡ 构建与同步 ▾`」下拉菜单，保持主操作区整洁。

### 旅程四：「图谱 ↔ 会话 ↔ 搜索」双向溯源闭环（对应 Spec 4）

- **US-4.1【从图谱事实一键溯源到原始对话】**
  - **作为**阿轩，**我想要**在查看图谱某个节点的某条事实时，直接点击它下方的 **`↗ 会话 xxxxxxx`** 来源胶囊，立刻跳转到「会话」页面打开产生这条知识的原始历史对话，并高亮显示该会话提炼出的全部知识卡片，**以便**我核实这条结论当时的上下文背景，或在发现整场对话都是废话时一键「整会话剔除」。
  - **验收标准 (AC)**：
    - [x] 事实来源为历史会话时渲染为可点击的青色胶囊，点击后自动切换到「会话」视图、定位选中该会话（若不在当前项目范围则自动扩大到全部会话范围查找），并对顶部「🧠 本会话产出的知识」卡片做高亮闪烁提示。

- **US-4.2【从会话与全文搜索反向跳回图谱】**
  - **作为**阿轩，**我想要**在看某条历史会话的「本会话产出的知识」卡片时，点击里面的 **`实体名 ↗`** 直接跳回知识图谱查看它的邻居关系；同时在 `⌘K` 面板搜到某段对话原文时，用 `⌘2` 打开对应会话，**以便**在「原文检索 → 会话上下文 → 结构化图谱」三者之间无缝穿梭。
  - **验收标准 (AC)**：
    - [x] 会话知识卡片中的实体名称可点击，点击后切换回「知识」视图并聚焦该实体。
    - [x] 全文检索（`⌘K` 面板的「历史会话」分区，走 `SearchSessions`）的每条命中结果可回车直达对应历史会话。

- **US-4.3【千级会话列表流畅滚动】**
  - **作为**阿轩，**我想要**在拥有数百上千条历史会话的项目中秒开「会话」页面，不会因为一次性挂载全部 DOM 节点而卡顿，**以便**顺畅浏览和筛选历史记录。
  - **验收标准 (AC)**：
    - [x] 会话列表采用增量渲染（首屏渲染前 60 条，滚动到底部或点击加载按钮每次追加 60 条），切换项目或输入筛选词时零卡顿。

### 旅程五：`⌘K` 全局命令/检索中心与开箱即用配置（对应 Spec 5）

- **US-5.1【`⌘K` 一站式全局检索与快捷命令】**
  - **作为**键盘党阿轩，**我想要**在应用任何页面按下 `⌘K`（或 `Ctrl+K`）呼出一个全局面板，输入任意词就能同时搜出匹配的**知识实体、事实、项目/知识域、历史会话原文以及快捷命令**，回车直达，**以便**用最短路径完成任何跳转或操作。
  - **验收标准 (AC)**：
    - [x] 空输入时展示高频动作（切换 6 大视图、触发增量建索引）与最近知识域。
    - [x] 输入关键词时，即时聚合展示：匹配的图谱实体（含命中事实/别名摘要）、匹配的项目/知识域、匹配的 SQLite 全文会话片段、以及匹配的动作指令。

- **US-5.2【设置页状态回填与自定义知识提炼模型】**
  - **作为**使用智谱 GLM 或标准 OpenAI 接口的用户，**我想要**在「设置 → 默认设置」里清楚看到我之前保存的默认 Provider 和默认模型，并能单独指定（或留空自动跟随默认模型）「**知识提炼模型**」，**以便**不依赖特定私有模型名也能顺利跑通「建索引」和「阅读文章」。
  - **验收标准 (AC)**：
    - [x] 打开设置页时自动调用 `GetDefaults()` 回填已保存的 `DefaultProvider`、`DefaultModel` 与 `GraphModel`。
    - [x] 保存默认设置时同步持久化 `GraphModel`；当 `GraphModel` 留空时，后端自动回退使用 `DefaultModel`。

## 4. 建议走查路径（端到端体验脚本）

你可以按以下 5 步快速走查上面设计的用户故事是否顺手：

1. **体验 `⌘K` 全局检索（US-5.1）**：打开 Axon-x，直接按 **`⌘K`**，输入任意业务词（如 `合同`、`glite` 或 `缓存`），观察是否同时出现图谱实体、事实摘要和历史会话，按回车直达目标节点。
2. **体验画布缩放与手动记知识（US-2.1, US-3.2）**：在「知识」页滚动鼠标滚轮缩放画布、按住空白处拖拽平移；点击顶栏 **「`+ 记一条知识`」** 录入一条测试知识，或点右侧详情面板标题旁的 **`✎`** 给实体改名（即使在 `wanlian +1` 自动归组状态下也可直接修改）。
3. **体验「图谱 ↔ 会话」双向溯源（US-4.1, US-4.2）**：在右侧实体事实下方点击青色的 **`↗ 会话 xxxxxxx`** 胶囊，观察是否自动跳到「会话」页并高亮闪烁顶部「🧠 本会话产出的知识」卡片；再点击卡片里的 **`实体名 ↗`** 跳回图谱。
4. **体验项目与多域对比选择器（US-1.1, US-1.2）**：在左下角统一的「项目与知识域」列表中点击某个知识域右侧的 **`+`** 叠加对比两个知识域，再点顶部「仅看单个」恢复；按 **`⌘B`** 试试折叠侧边栏。
5. **体验全文检索与设置回填（US-1.3, US-5.2）**：按 **`⌘K`** 呼出全局面板搜关键词、回车直达目标（历史会话命中会跳转对应会话）；按 **`⌘4`** 切到「设置」页确认默认模型与「知识提炼模型」已正常回填。
