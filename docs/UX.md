# Axon — UX / 交互设计文档

> 面向开发者用户的多模型 AI 桌面客户端。设计基调:克制、高效、键盘友好、深色为主。
> 本文只描述交互与布局,不含实现代码。事实源见 `docs/BRIEF.md`,不推翻其中已确认的决策。

---

## 0. 设计原则

1. **不打断心流** — 推荐模型、语义记忆提示都以"轻提示"形式呈现,默认可忽略,绝不弹模态框拦路。
2. **键盘优先** — 所有高频操作有快捷键;`⌘K` 命令面板是一等公民。
3. **信息密度适中** — 开发者能接受高密度,但流式阅读区要留白,代码块要清晰。
4. **可解释** — 自动选模型必须给出"为什么"(IQ / 成本 / 耗时),不做黑盒。
5. **数据永不丢** — 即时落盘,关窗重开原样恢复,UI 要传达这种"安心感"。

## 1. 信息架构

四个主视图,由最左侧图标导航栏(Rail)切换。会话是核心,故 Rail 第一项即"聊天",且默认进入。

```
Axon (单窗口应用)
│
├─ 聊天 Chat        ← 默认视图。会话列表 + 消息流 + 输入框
│   └─ 会话 Session (N 个,按时间分组)
│
├─ 归档 Archive     ← 全量历史检索:全文 + 语义,带筛选(模型/日期/成本/项目)
│
├─ 记忆 Memory      ← 语义记忆库:浏览已抽取的会话摘要与知识片段,可管理/删除
│
└─ 设置 Settings    ← Providers & API Key / 路由规则 / 外观 / 关于
    ├─ Providers    (OpenAI / Anthropic / 自定义 OpenAI-compatible)
    ├─ 路由 Routing  (任务类型→模型映射,来自 routing.json)
    ├─ 外观 Appearance
    └─ 关于 About
```

导航关系:Rail 常驻;聊天视图内含二级面板(会话列表);归档/记忆/设置为独立全宽视图,进入后 Rail 高亮切换。`⌘1~4` 直达四个主视图,`Esc` 从任意子视图退回聊天。

## 2. 主界面布局(聊天视图)

三栏结构:Rail(图标导航) + Sidebar(会话列表) + Main(聊天区)。模型选择器放在聊天区顶栏右侧,输入框上方悬浮一条"推荐条"(见 3.2)。

```
┌──┬──────────────────┬─────────────────────────────────────────────────┐
│  │  ⌕ 搜索会话  ⌘K   │  日常开发 · gpt-5.6-sol           [模型 ▾]  ⋯   │ ← 顶栏
│💬│──────────────────│─────────────────────────────────────────────────│
│  │ + 新会话   ⌘N     │                                                 │
│📥│                  │   You                                     14:02  │
│  │ ▸ 今天            │   帮我把这段 rate limiter 改成滑动窗口          │
│🧠│  ● 滑动窗口限流 ⟳ │                                                 │
│  │   支付重构方案    │   ┌───────────────────────────────────────────┐ │
│⚙ │ ▸ 昨天            │   │ Assistant · gpt-5.6-sol          14:02   │ │
│  │   K8s 探针配置    │   │ 好的,滑动窗口的核心是记录每个请求的时间戳… │ │
│  │   Svelte store    │   │                                           │ │
│  │ ▸ 更早            │   │ ```go                                     │ │
│  │   Flyway 迁移     │   │ func (l *Limiter) Allow() bool {          │ │
│  │   ...             │   │   now := time.Now()                       │ │
│  │                  │   │   ...                                     │ │
│  │                  │   │ ```                     [复制] [插入编辑器]│ │
│  │                  │   └───────────────────────────────────────────┘ │
│  │                  │   ▍流式光标闪烁中…                    [■ 停止]  │
│  │                  │─────────────────────────────────────────────────│
│  │                  │  💡 推荐 gpt-5.6-sol·medium ~$3.7 [用它] [改▾]  │ ← 推荐条(轻提示)
│  │                  │ ┌─────────────────────────────────────────────┐ │
│  │ ⚙ 设置            │ │ 输入消息…            (⏎ 发送 · ⇧⏎ 换行)     │ │
│  │ ● OpenAI 已连接   │ │                                    [↑ 发送]│ │
│  └──────────────────│ └─────────────────────────────────────────────┘ │
└──┴──────────────────┴─────────────────────────────────────────────────┘
 Rail       Sidebar                      Main (聊天区)
```

区域职责:
- **Rail(48px)**: 四视图图标 + 底部连接状态灯(绿=已连接/灰=未配置/红=报错)。
- **Sidebar(240px, 可折叠 `⌘\`)**: 顶部搜索(点击=`⌘K` 命令面板),会话按"今天/昨天/更早"分组。`●` 当前会话,`⟳` 表示该会话命中了语义记忆(见 3.3)。
- **Main**: 顶栏(当前会话任务类型 + 生效模型 + 模型选择器) / 消息流(用户右对齐轻底,助手左对齐带卡片,代码块等宽字体带复制) / 推荐条 / 输入框(自动增高,`⏎` 发送、`⇧⏎` 换行)。
- 流式输出时底部显示流式光标与 `[■ 停止]`;可随时打断。

### 模型选择器(顶栏 `[模型 ▾]`,快捷键 `⌘/`)

```
┌─────────────────────────────────────────┐
│ 为本会话选择模型              ⌘/ 关闭    │
├─────────────────────────────────────────┤
│ 任务类型  [日常开发 ▾]  ← 改这个会联动推荐│
│                                         │
│ ● gpt-5.6-sol · medium   推荐            │
│     IQ 95.1 · ~$3.72 · ~17m             │
│ ○ gpt-5.5 · high         备选            │
│     IQ 95.1 · ~$3.71 · ~17m             │
│ ○ 手动选择其他模型…       ▸              │
├─────────────────────────────────────────┤
│ □ 记住此会话的选择(不再自动推荐)        │
└─────────────────────────────────────────┘
```

数据直接来自 `routing.json` 的 primary/alternate 字段(model/effort/iq/cost_usd/minutes)。

## 3. 关键交互流(对应四个痛点)

### 3.1 归档 — 浏览、搜索、关窗恢复(痛点 1)

会话即时落盘(SQLite WAL),无"保存"概念。**关窗重开自动恢复到上次的会话与滚动位置**,顶部一条 3 秒自动消失的提示带来安心感。

归档视图(`⌘2`)是全量检索台,支持全文 + 语义混合搜索,左侧筛选,右侧结果预览:

```
┌──┬──────────────────────────────────────────────────────────────────┐
│📥│ ⌕ 搜索所有会话(全文 + 语义)                          ⌘K        │
│  │─────────────────────┬────────────────────────────────────────────│
│  │ 筛选                 │  38 条结果 · 按相关度排序 ▾                 │
│  │ ☑ 全文  ☑ 语义       │                                            │
│  │ 模型 [全部 ▾]        │  ● 滑动窗口限流实现            2d 前 · $3.7 │
│  │ 日期 [近30天 ▾]      │    …改成滑动窗口,核心是记录每个请求…       │
│  │ 项目 [axon ▾]        │    gpt-5.6-sol · 命中: "限流" "sliding"     │
│  │ 成本 [不限 ▾]        │                                            │
│  │                     │  ○ 支付模块重构方案            5d 前 · $6.9 │
│  │ 清空筛选             │    …幂等键 + 状态机,避免重复扣款…          │
│  └─────────────────────┴────────────────────────────────────────────│
│                            [打开会话 ⏎]  [继续对话]  [导出 md]        │
└──┴──────────────────────────────────────────────────────────────────┘
```

- 关窗恢复:重开后落在上次会话,顶部提示 `已恢复上次会话(38 条已归档)`。
- 全文用 SQLite FTS,语义用 sqlite-vec;结果标注"命中: 关键词"或"语义相近"以示区分。
- 断网时语义那半降级(见 5.4),全文仍可用,UI 明确告知。

### 3.2 自动选模型 — 轻推荐,不打断(痛点 2)

原则:**默认已选好,推荐条只是"告知 + 一键改"**,不弹窗、不强制确认。

新会话时,系统对首条输入做启发式分类 → 匹配 `routing.json` → 在输入框上方渲染推荐条:

```
新会话,用户还没输入:
  💡 将根据任务自动选模型                                    [默认: 日常开发 ▾]

用户输入后(分类命中"难题攻坚"):
  💡 推荐 gpt-5.6-sol · xhigh  ~$6.86 · ~26m   [用它 ⌘⏎] [改 ▾] [✕ 本会话不再提示]
```

交互细节:
- 用户**什么都不点直接发送** = 采用推荐(零摩擦)。`⌘⏎` = 显式"用它并发送"。
- `[改 ▾]` 展开模型选择器(见 2.),`✕` 后本会话固定为默认模型不再提示。
- 分类只在**会话首条**和用户显式点"重新评估"时触发,避免每轮打断。
- 若预估成本高于阈值(如单次 >$10 的 ultra 档),推荐条变琥珀色并提示 `高成本档位,确认?`,此时才需要一次点击确认。

### 3.3 语义记忆 — "你以前处理过类似的…"(痛点 3)

针对"大概有印象但记不清关键词"。开新会话或输入首条后,对输入做 embedding → sqlite-vec 检索历史会话摘要 → 命中则在消息流顶部插入一条**可折叠的记忆卡**(非模态,可忽略):

```
┌───────────────────────────────────────────────────────────────┐
│ 🧠 你以前处理过 2 个相似问题                        [展开 ▾] [✕]│
├───────────────────────────────────────────────────────────────┤
│ · 滑动窗口限流实现        2d 前 · 相近度 92%   [看] [＋注入上下文]│
│ · Redis 令牌桶限流        3w 前 · 相近度 78%   [看] [＋注入上下文]│
│                                                                │
│   注入后会把该会话的摘要作为系统上下文加入本轮,并标注来源。      │
└───────────────────────────────────────────────────────────────┘
```

- `[看]` = 在右侧滑出预览原会话;`[＋注入上下文]` = 一键把该会话摘要作为附加上下文注入本轮请求。
- 注入后输入框上方出现可移除的上下文药丸:`📎 已注入: 滑动窗口限流 ✕`,让用户清楚"AI 现在知道了什么"。
- Sidebar 中命中记忆的会话标 `⟳`。默认折叠、`✕` 即消失,绝不阻塞输入。

### 3.4 设置 — 安全配置 API Key(痛点 4 前置 + 安全)

强调:key 存 macOS Keychain 不落明文;输入框脱敏显示;提供连通性测试。

```
┌──┬──────────────────────────────────────────────────────────────────┐
│⚙ │ 设置 › Providers                                                  │
│  │──────────────────────────────────────────────────────────────────│
│  │  OpenAI                                          ● 已连接          │
│  │   API Key   [ sk-••••••••••••••••3f2a ]  [显示] [更新] [测试]      │
│  │   Base URL  [ https://api.openai.com/v1        ]                   │
│  │   🔒 存储于 macOS Keychain,不写入配置文件                          │
│  │                                                                    │
│  │  Anthropic                                       ○ 未配置          │
│  │   API Key   [ 粘贴 sk-ant-… 后自动脱敏          ]  [保存] [测试]    │
│  │                                                                    │
│  │  + 添加自定义 Provider (OpenAI-compatible)                         │
│  │──────────────────────────────────────────────────────────────────│
│  │  Embedding 模型  [ text-embedding-3-small ▾ ]  用于语义记忆检索    │
└──┴──────────────────────────────────────────────────────────────────┘
```

- 输入即脱敏:保存后只显示后 4 位,`[显示]` 需再次交互才短暂明文,焦点离开即复原。
- `[测试]` 发一个最小请求验证 key 与网络,结果内联显示(✅ 234ms / ❌ 401 无效 key)。
- key 只经 Go 后端写入 Keychain,前端永不持久化明文。

## 4. 组件清单(Svelte,供开发参考)

按视图/职责组织。命名用英文,便于代码落地。

**布局骨架**
- `AppShell` — 整体三栏骨架 + 全局快捷键分发。
- `NavRail` — 左侧图标导航 + 连接状态灯,`⌘1~4` 切换。
- `Sidebar` — 会话列表容器,可折叠。
- `CommandPalette` — `⌘K` 命令面板(搜索会话 / 跳转 / 执行动作)。

**聊天视图**
- `SessionList` / `SessionListItem` — 分组会话列表,含 `●`当前、`⟳`记忆命中标记。
- `ChatView` — 消息流容器,管理滚动恢复与自动滚动。
- `MessageBubble` — 单条消息(区分 user/assistant),含时间、模型标签。
- `CodeBlock` — 等宽代码块 + 语法高亮 + `[复制]`。
- `StreamingIndicator` — 流式光标 + `[■ 停止]`。
- `ModelBadge` / `ModelPicker` — 顶栏模型标签与选择弹层。
- `RecommendationBar` — 推荐条(3.2),轻提示逻辑。
- `MemoryCard` — 记忆卡(3.3),折叠/展开/注入。
- `ContextPill` — 已注入上下文药丸(可移除)。
- `MessageInput` — 自增高输入框,`⏎`/`⇧⏎` 处理。

**归档 / 记忆**
- `ArchiveView` — 检索台布局。
- `SearchBar` — 全文+语义混合搜索输入。
- `FilterPanel` — 模型/日期/项目/成本筛选。
- `SearchResultItem` — 结果条,含命中高亮与来源标注。
- `MemoryView` / `MemoryItem` — 记忆库浏览与管理(删除/查看)。

**设置**
- `SettingsView` — 设置左侧分节导航 + 内容区。
- `ProviderCard` — 单个 Provider 配置卡。
- `SecretInput` — 脱敏 key 输入(显示/隐藏/更新)。
- `ConnectionTestButton` — 连通性测试与内联结果。

**通用**
- `Toast` — 顶部轻提示(如"已恢复上次会话")。
- `EmptyState` — 空状态占位(见 5)。
- `ErrorBanner` — 错误/降级横幅。
- `StatusDot` — 连接状态灯。

## 5. 空状态与错误态

### 5.1 首次打开,未配 Key
主区域居中引导,不给空白。CTA 直达设置。
```
              ┌─────────────────────────────┐
              │           ◇ Axon            │
              │   先连接一个模型来开始对话     │
              │                             │
              │   [ 配置 API Key → ]  ⌘,     │
              │   密钥安全存储于 Keychain     │
              └─────────────────────────────┘
```

### 5.2 无历史(新用户已配 key)
会话列表空:`还没有会话。⌘N 开始第一个对话。`
归档/记忆视图空:`归档为空。你的对话会自动保存在这里,关窗也不会丢。`

### 5.3 API 报错
输入框上方红色 `ErrorBanner`,消息不丢、可重试:
```
⚠ 请求失败:429 速率限制。 [重试] [切换模型] [查看详情]
```
- 401/403 → `key 无效或过期` + `[去设置]`。
- 网络超时 → `连接超时,已保留你的输入` + `[重试]`。
- 流式中断 → 保留已收到内容,末尾标 `⚠ 输出中断` + `[继续生成]`。

### 5.4 断网 / embedding 检索失败
语义功能优雅降级,不阻断主流程:
- 记忆卡区域显示灰条:`离线中,语义记忆暂不可用。全文搜索仍可用。`
- 归档语义搜索自动回退到纯全文,筛选栏 `☑语义` 置灰并注明 `需要网络`。
- 恢复网络后自动重试并移除降级提示。

## 6. 视觉基调

**气质**: 深色为主、开发者友好、克制。接近现代代码编辑器(VS Code / Linear 的冷静感),低饱和、少装饰、内容优先。默认深色,支持跟随系统。

**字体**:
- UI/正文:系统字体栈(macOS 用 `-apple-system`/SF Pro),清晰紧凑。
- 代码/等宽:`ui-monospace, "SF Mono", "JetBrains Mono", Menlo`。代码块、模型名、成本数字用等宽,便于对齐扫读。

**设计 Token(深色,建议起点)**:

| Token            | 值        | 用途                     |
|------------------|-----------|--------------------------|
| `--bg-base`      | `#0D1117` | 主背景(最底层)          |
| `--bg-surface`   | `#161B22` | 侧边栏 / 卡片 / 输入框    |
| `--bg-elevated`  | `#21262D` | 弹层 / 命令面板 / hover   |
| `--border`       | `#30363D` | 分隔线 / 边框            |
| `--text-primary` | `#E6EDF3` | 主文字                   |
| `--text-muted`   | `#8B949E` | 次要文字 / 时间戳 / 提示  |
| `--accent`       | `#3B82F6` | 主色:按钮/链接/当前项    |
| `--accent-fg`    | `#FFFFFF` | 主色上的文字             |
| `--success`      | `#3FB950` | 已连接 / 测试通过        |
| `--warning`      | `#D29922` | 高成本 / 降级提示        |
| `--danger`       | `#F85149` | 错误 / 断连              |

- 圆角:卡片 `8px`,按钮/输入 `6px`,药丸 `full`。
- 间距:8px 基准网格。消息流左右留白 `≥16px`,阅读宽度上限约 `760px` 防止长行。
- 强调克制:主色仅用于当前项、主按钮、链接;状态色只用于状态。
