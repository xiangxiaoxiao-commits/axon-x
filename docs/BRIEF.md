# Axon — 项目简报 (所有角色的共同上下文)

> 这是全体协作角色的"事实源"。任何角色开工前先读本文件。不要推翻这里已确认的决策。

## 一句话定位
一个**多模型 AI 桌面客户端**,解决终端使用 AI 时的四大痛点。

## 要解决的四个痛点 (来自真实用户)
1. **会话归档** — 终端里用 AI,关掉终端历史就全丢了,无法归档回看。
2. **按任务自动选模型** — 不同任务该用哪个模型最省 token、性价比最高,用户不清楚,想自动推荐。
3. **跨会话语义记忆** — 遇到"以前处理过的同类问题",AI 想不起来,导致重复劳动。用户"大概有印象但记不清关键词"。
4. **可安装可分享** — 要做成真正的桌面应用,能装、能分享给别人 (最终出安装包)。

## 已敲定的技术决策 (不要改)
- **形态**: 桌面 GUI 应用 (不是纯 CLI)。
- **框架**: Wails v2 (Go 后端 + Web 前端)。前端用 **Svelte**。
- **模型接入**: 直连各家 HTTP API (OpenAI-compatible + Anthropic 原生)。用户自己配 API key。
- **归档存储**: SQLite (开 WAL,即时落盘,append-only,关窗/崩溃不丢)。
- **语义检索**: embedding + **sqlite-vec** 向量检索。embedding 默认走 API (如 text-embedding-3-small),抽象成接口以便日后换本地/Ollama。
- **API key 存储**: macOS Keychain,不落明文。
- **打包**: `wails build` → `.app` → `.dmg`。默认 ad-hoc 签名 (首次打开需右键→打开)。
- **代号**: axon。
